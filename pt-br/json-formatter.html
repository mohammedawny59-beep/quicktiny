Formate e valide seu JSON em segundos

Cole JSON bruto ou minificado e o QuickTiny vai validar e formatar com indentação de dois espaços. Se estiver inválido — incluindo problemas comuns em JSON copiado do ChatGPT ou Claude — você verá uma explicação em linguagem simples e uma correção com um clique para os casos mais comuns.

Testar agora

Como corrigir JSON inválido

Quando seu JSON não é reconhecido, o QuickTiny explica o motivo em linguagem simples junto ao erro original do validador — por exemplo, apontando uma vírgula sobrando, uma aspas simples onde deveria haver uma dupla, ou uma chave sem aspas. Se o problema for um dos poucos casos comuns e sem ambiguidade (vírgulas sobrando, strings com aspas simples, chaves sem aspas — o tipo de coisa que aparece o tempo todo em JSON copiado do ChatGPT, do Claude ou de arquivos de configuração editados manualmente), clique em "Tentar corrigir problemas comuns" e o QuickTiny corrige automaticamente e diz exatamente o que mudou. Se o JSON estiver incompleto — faltando um colchete de fechamento porque uma resposta foi cortada — o QuickTiny avisa em vez de adivinhar o que falta, já que não há como reconstruir com segurança um conteúdo que nunca existiu.

Principais vantagens

  • Explicações em linguagem simples junto ao erro original do validador.
  • Correção automática com um clique para vírgulas sobrando, aspas simples e chaves sem aspas.
  • Indentação de dois espaços para um JSON legível e fácil de comparar.
  • Funciona localmente — seu JSON nunca é enviado a um servidor, registrado ou armazenado.
  • Copie o resultado formatado com um clique.

Privacidade

O Formatador de JSON funciona inteiramente no seu navegador, usando JavaScript local. Seu JSON é processado no seu próprio dispositivo e nunca é enviado, registrado ou armazenado pelo QuickTiny — nem mesmo ao usar a correção automática. Não há histórico nem registro do que você colou.

Perguntas frequentes

Meus dados JSON são enviados para algum lugar?

Não. A análise, a formatação e a correção automática acontecem inteiramente no seu navegador. Nada é enviado, registrado ou armazenado — o QuickTiny não guarda histórico do que você colou.

Isso corrige JSON inválido?

Sim, para problemas comuns e sem ambiguidade: vírgulas sobrando, aspas simples em vez de duplas, e chaves de objeto sem aspas. Clique em "Tentar corrigir problemas comuns" depois de uma validação que falhou e o QuickTiny corrige e diz exatamente o que mudou.

Isso corrige JSON copiado do ChatGPT ou do Claude?

Muitas vezes, sim — os problemas mais comuns em JSON gerado por IA (vírgulas sobrando, alguma aspas simples ocasional) são exatamente o que a correção automática resolve. Porém, se a resposta foi cortada no meio, o JSON está realmente incompleto, e o QuickTiny vai avisar em vez de adivinhar um conteúdo que nunca foi gerado.

O que a mensagem de erro me diz?

Você verá o erro nativo do validador de JSON do navegador, além de, quando o QuickTiny conseguir identificar a causa provável, uma explicação em linguagem simples do que provavelmente está errado e por quê.

O que a correção automática não consegue resolver?

Qualquer coisa que exija adivinhar conteúdo que falta — como uma resposta truncada sem os colchetes de fechamento, ou um valor ambíguo sem mais contexto. O QuickTiny só aplica correções que consegue fazer com certeza; ele nunca muda silenciosamente o significado dos seus dados.

Dá para minificar JSON com essa ferramenta?

Essa ferramenta é focada em formatar, validar e corrigir. Para minificar, remova a indentação manualmente ou use JSON.stringify sem um argumento de espaçamento no seu próprio código.

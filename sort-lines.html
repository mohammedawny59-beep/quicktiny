Sort Lines — A→Z or Z→A

Paste a list and sort it alphabetically or in reverse — useful for tidying keyword lists, file names or reference lists.

How to use Sort Lines

  1. Paste your list, one item per line.
  2. Optionally check "Remove empty lines".
  3. Click "Sort A → Z" or "Sort Z → A".
  4. Copy the sorted result.

Key benefits

  • Locale-aware alphabetical sorting, case-insensitive.
  • Optional empty-line removal.
  • Instant, no file upload.
  • Useful for keyword lists, references and file names.

Privacy

Sort Lines runs entirely in your browser using local JavaScript. Your files and text are processed on your own device and are never uploaded to QuickTiny's servers.

Frequently asked questions

Is sorting case-sensitive?

No, sorting uses case-insensitive comparison so "Banana" and "apple" sort by letter, not by capitalization.

Does it sort numbers as numbers?

Lines are sorted as text, so "10" comes before "2" alphabetically. This tool doesn't do numeric sorting.

Can I undo a sort?

Sorting overwrites the box, so copy your original list first if you want to keep the unsorted version.

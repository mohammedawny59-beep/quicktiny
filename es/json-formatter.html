Formateador y Validador de JSON

Pega JSON sin formato o minificado y QuickTiny lo validará y formateará con sangría de dos espacios. Si es inválido — incluyendo problemas comunes en JSON copiado de ChatGPT o Claude — verás una explicación en lenguaje sencillo y una corrección con un clic para los casos más comunes.

Pruébalo ahora

Cómo corregir JSON inválido

Cuando tu JSON no se puede analizar, QuickTiny explica por qué en lenguaje sencillo junto al error original del validador — por ejemplo, señalando una coma sobrante, una comilla simple donde debería haber una doble, o una clave sin comillas. Si el problema es uno de un puñado de casos comunes e inequívocos (comas sobrantes, cadenas con comillas simples, claves sin comillas — el tipo de cosas que aparecen constantemente en JSON copiado de ChatGPT, Claude o archivos de configuración editados a mano), haz clic en "Intentar corregir problemas comunes" y QuickTiny lo corregirá automáticamente y te dirá exactamente qué cambió. Si el JSON está incompleto — le falta un corchete de cierre porque una respuesta se cortó — QuickTiny te lo dirá en lugar de adivinar qué falta, ya que no hay forma segura de reconstruir contenido que nunca existió.

Ventajas principales

  • Explicaciones en lenguaje sencillo junto al error original del validador.
  • Corrección automática con un clic para comas sobrantes, comillas simples y claves sin comillas.
  • Sangría de dos espacios para un JSON legible y fácil de comparar.
  • Funciona localmente — tu JSON nunca se envía a un servidor, ni se registra ni se guarda.
  • Copia el resultado formateado con un clic.

Privacidad

El Formateador de JSON funciona enteramente en tu navegador usando JavaScript local. Tu JSON se procesa en tu propio dispositivo y nunca se sube, registra ni almacena por parte de QuickTiny — ni siquiera al usar la corrección automática. No hay historial ni registro de lo que has pegado.

Preguntas frecuentes

¿Mis datos JSON se suben a algún sitio?

No. El análisis, formateo y corrección automática ocurren enteramente en tu navegador. No se sube, registra ni almacena nada — QuickTiny no guarda un historial de lo que has pegado.

¿Esto puede corregir JSON inválido?

Sí, para problemas comunes e inequívocos: comas sobrantes, comillas simples en lugar de dobles, y claves de objeto sin comillas. Haz clic en "Intentar corregir problemas comunes" después de una validación fallida y QuickTiny lo corregirá y te dirá exactamente qué cambió.

¿Esto puede corregir JSON copiado de ChatGPT o Claude?

A menudo, sí — los problemas más comunes en JSON generado por IA (comas sobrantes, alguna comilla simple ocasional) son exactamente lo que corrige la función automática. Sin embargo, si la respuesta se cortó a la mitad, el JSON está realmente incompleto, y QuickTiny te lo dirá en lugar de adivinar contenido que nunca se generó.

¿Qué me indica el mensaje de error?

Verás el error nativo del validador de JSON del navegador, más, cuando QuickTiny puede identificar la causa probable, una explicación en lenguaje sencillo de qué es probable que esté mal y por qué.

¿Qué no puede corregir la función automática?

Cualquier cosa que requiera adivinar contenido que falta — como una respuesta truncada a la que le faltan los corchetes de cierre, o un valor ambiguo sin más contexto. QuickTiny solo aplica correcciones que puede hacer con certeza; nunca cambiará silenciosamente el significado de tus datos.

¿Puedo minificar JSON con esta herramienta?

Esta herramienta se centra en formatear, validar y corregir. Para minificar, quita la sangría manualmente o usa JSON.stringify sin un argumento de espaciado en tu propio código.

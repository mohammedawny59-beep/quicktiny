    Frequently asked questions
    
    
    Which regex flavor does this use?
    Your browser's JavaScript engine (ECMAScript 2024), including named groups, lookbehind and Unicode properties. Most patterns work the same in Python, PHP (PCRE) and Java; the code export converts the syntax that differs.
    
    
    Why does my pattern only find one match?
    Without the g (global) flag JavaScript stops after the first match. Turn on g to see them all.
    
    
    What is catastrophic backtracking?
    Patterns like (a+)+$ can take exponential time on text that almost matches. Real servers have gone down because of it. Here the test is stopped after 1.5 seconds and you're told why — rewrite the nested quantifier to fix it.
